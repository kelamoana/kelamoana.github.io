# kelamoana.github.io

Personal site of Cullen Poʻokela Moana, served by GitHub Pages at https://kelamoana.github.io.

Plain HTML and CSS, no build step.

| Path | What it is |
|---|---|
| `index.html` | Home: intro, experience, projects, about, contact |
| `projects/mauka-to-makai.html` | Case study for the Mauka to Makai game |
| `assets/css/site.css` | All styles. Light and dark themes are CSS variables at the top. |
| `assets/js/theme.js` | Follows the system theme until the visitor uses the toggle, then remembers the choice |
| `images/headshot.jpg` | Portrait |

To preview locally: `python3 -m http.server` in this folder, then open http://localhost:8000.
